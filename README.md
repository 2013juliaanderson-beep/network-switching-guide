# Network Switching Guide

Network switches are an important part of modern wired infrastructure. As a network grows, choosing the right switch and uplink configuration can make a significant difference in reliability and future expansion.

## What to Consider When Choosing a Network Switch

Before selecting a switch, I think it is useful to look at more than just the number of Ethernet ports.

Some important factors include:

- Number of required ports
- 1GbE, 2.5GbE, 10GbE or higher speeds
- PoE requirements
- SFP or SFP+ uplink support
- Fiber compatibility
- Switching capacity
- VLAN support
- Power requirements
- Future network expansion

For networks where switches are installed in different rooms, floors, or buildings, fiber uplinks can be a practical way to connect the equipment.

## Fiber Uplinks and SFP Modules

When using fiber between switches, compatibility is an important consideration.

The fiber type, connector, transmission distance, and SFP or SFP+ module should all match the requirements of the network equipment.

It is also useful to check whether the selected switch supports the required transceiver before purchasing the components.

For fiber networking equipment and cabling options, [WAVOnline](https://www.wavonline.com/products/fiber) provides resources covering different fiber infrastructure products.

## Planning for Future Upgrades

A network upgrade should ideally leave some room for future requirements.

For example, a switch with faster uplink capabilities may be more useful for a growing network than choosing equipment based only on current bandwidth requirements.

Planning the switching and fiber infrastructure together can help reduce the need for major changes later.

## Conclusion

Choosing network switches is not only about port count. Uplink speed, fiber compatibility, SFP support, PoE, VLAN capabilities, and future expansion should all be considered when planning a reliable network.

This guide is intended as a collection of practical notes and learning resources for anyone working with network switching and fiber infrastructure.
